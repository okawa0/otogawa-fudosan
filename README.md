# 乙川不動産株式会社 コーポレートサイト

## 概要
このサイトは、不動産業界の架空サイトとして制作したポートフォリオです。
ユーザーが「岡崎の土地と暮らし」に関する情報を探しやすく、サービス内容を理解しやすいように、情報設計・デザイン・コーディングを行いました。

## 工夫した点

### 1. レスポンシブ対応
スマートフォン・タブレット・PCで見やすくなるように、主要なセクションの余白・文字サイズ・画像の比率を調整しました。特にヒーローセクションと物件一覧は、各デバイスで最適な表示になるよう配慮しています。

### 2. 保守しやすいCSS設計
BEMを意識したクラス設計にし、コンポーネント指向でスタイルを記述することで、後から修正や機能追加がしやすいようにしました。Sassの分割機能を利用し、`_base.scss`, `_variables.scss`, `_styles.scss` など、用途ごとにファイルを分けて管理しています。

### 3. WordPressで更新しやすい構成
「新着・おすすめ物件」や「お客様の声」、「よくある質問」、「スタッフ紹介」など、クライアント側で頻繁に更新が必要になりそうな部分は、WordPressのカスタム投稿タイプとカスタムフィールドで管理できるように実装しました。これにより、専門知識がなくても容易にコンテンツを更新できます。

## 苦労した点
レスポンシブ対応において、特に広範なコンテンツを持つ「サービス内容」や「会社概要」セクションで、画像とテキストのバランスが崩れやすかったため、ブレイクポイントごとに詳細なレイアウト調整が必要でした。また、WordPress化の際には、静的HTMLで作成したページをPHPのテンプレートパーツ（`header.php`, `footer.php` など）へ分割し、共通部分を一元的に管理できるよう構造化するのに時間を要しました。

## 今後改善したい点
- JavaScriptのアニメーションをより自然でリッチにする (例: スクロールアニメーションの追加、インタラクティブ要素の強化)
- Lighthouseのスコア改善 (特にパフォーマンスとアクセシビリティ)
- アクセシビリティ対応の強化 (ARIA属性の追加、キーボードナビゲーションの改善など)
- 管理画面の入力項目をさらに使いやすくする (カスタムフィールドのUI改善、説明文の追加)
- 実案件を想定した保守運用設計を追加する (バックアップ体制、セキュリティ対策、更新手順の明文化など)
