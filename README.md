# 乙川不動産株式会社 コーポレートサイト

## 概要
このサイトは、不動産業界の架空サイトとして制作したポートフォリオです。
ユーザーが「岡崎の土地と暮らし」に関する情報を探しやすく、サービス内容を理解しやすいように、情報設計・デザイン・コーディングを行いました。

掲載している会社情報・電話番号・住所・免許番号・人物名・お客様の声などは、ポートフォリオ用のダミーデータです。

## デモ仕様
- お問い合わせフォームは送信処理を行わないダミーフォームです。送信時はJavaScriptで受付メッセージを表示するのみで、メール送信やデータ保存は行いません。
- 物件情報は一覧表示を想定しており、物件詳細ページは実装していません。
- 電話番号・住所・免許番号などの事業者情報は、架空サイトとしてのダミー表記です。

## 工夫した点

### 1. レスポンシブ対応
スマートフォン・タブレット・PCで見やすくなるように、主要なセクションの余白・文字サイズ・画像の比率を調整しました。特にヒーローセクションと物件一覧は、各デバイスで最適な表示になるよう配慮しています。

### 2. 保守しやすいCSS設計
BEMを意識したクラス設計にし、コンポーネント指向でスタイルを記述することで、後から修正や機能追加がしやすいようにしました。Sassの分割機能を利用し、`_base.scss`, `_variables.scss`, `_styles.scss` など、用途ごとにファイルを分けて管理しています。

### 3. WordPressで更新しやすい構成
「新着・おすすめ物件」や「物件検索」に掲載する物件情報を、WordPressのカスタム投稿タイプとカスタムフィールドで管理できるように実装しました。トップページへのおすすめ表示、物件種別・価格・所在地などの入力項目を用意し、管理画面から更新しやすい構成にしています。

## 苦労した点
レスポンシブ対応において、特に広範なコンテンツを持つ「サービス内容」や「会社概要」セクションで、画像とテキストのバランスが崩れやすかったため、ブレイクポイントごとに詳細なレイアウト調整が必要でした。また、WordPress化の際には、静的HTMLをテーマ化し、物件情報をカスタム投稿タイプとして扱えるようにする部分の設計に時間を要しました。

## 今後改善したい点

- アクセシビリティ対応の強化 (ARIA属性の追加、キーボードナビゲーションの改善など)
- 管理画面の入力項目をさらに使いやすくする (カスタムフィールドのUI改善、説明文の追加)
- 実案件を想定した保守運用設計を追加する (バックアップ体制、セキュリティ対策、更新手順の明文化など)
